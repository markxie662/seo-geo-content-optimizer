# Google SEO 入门指南覆盖表

核验日期：2026-10-15。指定的[简体中文 SEO 入门指南](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=zh-cn)页面显示最后更新于 2025-12-18。

本表是对指南全部正文章节的原创操作化提炼，供核对内容规划是否遗漏重要维度。它不是默认技术审计清单；页面不存在图片、视频、广告或用户投稿等内容时，标记“不适用”即可。具体观察须有 URL 或页面证据，无法验证的事项不得当作已通过。

## 正文章节映射

| 原章节或主题 | 内容优化检查 | 所需证据或技术交接条件 |
|---|---|---|
| Google 搜索的工作原理 | 区分内容被发现、被读取与满足读者任务，不把改稿等同于收录或排名 | 已读取页面只能证明其内容；索引状态需要独立证据 |
| 多久看到效果 | 为改动保留基线并安排复查，不承诺即时提升 | 记录改动日期与可用表现数据；尚无数据就列待观察项 |
| 帮助 Google 找到内容 | 检查重要内容是否有导航或相关页面引荐，记录 URL 发现路径 | 使用实际链接及可用 sitemap；`site:` 仅作线索，不能证明清单完整 |
| 向 Google 与用户呈现相同网页 | 内容结论以实际读到的正文为准，注意地域版本差异 | 工具读不到不等于 Google 读不到；有明确资源屏蔽或呈现障碍证据时交接 |
| 不希望网页出现在搜索中 | 尊重页面的公开与索引意图，不把所有页面都列为引流对象 | 发现明确索引控制与既定目标冲突时交接，不擅自解除控制 |
| 整理网站 | 优先改善导航名称、页面职责和内容关系 | 依据已发现页面；不因目录不理想就建议全站迁移 |
| 描述性网址 | 检查路径与页面主题是否易理解 | URL 可作可读性建议；已有 URL 变更须另行评估技术影响 |
| 相似主题归组 | 让相近内容有清晰入口和上下文引荐 | 以现有分类与导航为证；大型站目录或抓取策略仅在确有问题时交接 |
| 减少重复内容 | 找出样本中职责重叠的内容，建议区分、整合或补充 | 比较具体页面；重定向或 canonical 交由技术处理，不能据样本宣布全站重复率 |
| 让网站有趣且实用 | 检查原创价值、可读结构、时效、经验及可靠来源 | 引用页面片段与可追溯素材；不能虚构专家、实验或更新时间 |
| 预期读者搜索字词 | 用不同熟悉程度的读者任务组织表达，避免强塞精确词形 | 无查询数据时标为候选意图；不编造搜索量或需求强度 |
| 避免干扰广告 | 判断广告或插页是否遮挡正文、打断任务 | 仅报告实际观察到的阻碍；需要改展示行为时提供交接 |
| 指向相关资源 | 检查关键论断的来源与读者下一步所需链接 | 逐条核对相关性、目标与上下文；不为链接数量凑链接 |
| 优质链接文字 | 将含混锚文本改为能预期目标内容的自然文字 | 对照链接前后文及目标页；无真实 `href` 的关键导航可交接 |
| 何时提供链接 | 区分正常引用、付费链接和用户投稿 | 普通引用不一律 nofollow；发现付费或 UGC 场景时提示相应关系标记 |
| 搜索结果外观与标题链接 | 提供独特、准确、简洁的标题，与主要内容及语言一致 | 对照当前标题和正文；不保证搜索结果逐字采用，不设硬性字符数 |
| 摘要 | 为具体页面写有信息量的描述，并改善正文可摘取表达 | 使用该页事实；描述只是候选，不能承诺控制所有查询下的摘要 |
| 图片及相关文字 | 检查图片清晰度、邻近说明与内容关系 | 根据实际图像和上下文判断；不靠文件名臆测图像 |
| 图片替代文本 | 为承担信息或链接作用的图片写恰当描述 | 需要看见图片及其用途；不将关键词清单当作 alt |
| 视频 | 检查承载页、附近说明、标题与描述能否说明视频价值 | 依据可查看的视频或可靠文字材料；播放或发现障碍才交接 |
| 推广网站 | 提出与受众任务相符的传播方向，避免过度宣传和操纵链接 | 基于已知渠道与真实素材；建议不等于执行发帖、购买链接或投放 |
| 后续：Search Console | 把有数据的观察与公开页面审阅分开 | 无权限时列待取数据；不声称已查看索引、查询或人工处置报告 |
| 后续：长期维护 | 将过期、职责冲突和素材欠缺转为可复查任务 | 记录页面与复查条件；迁移、多语言等复杂工作另行交接 |
| 后续：结构化数据 | 仅考虑与真实页面内容相符的功能 | 核对可见内容与具体类型要求；实现交接，不自动铺设 schema |
| 了解资讯与提问 | 在规则不确定或易变化时复核官方资料 | 优先文档与官方更新；论坛和社交讨论只能作为待核实线索 |

## “不应重点关注”逐项防误用

以下规则用于纠正错误优化目标，不作为生成更多工作项的理由。

| 指南主题 | Skill 必须避免的误用 |
|---|---|
| meta keywords | 不将添加关键词元标记列为 Google 搜索优化任务 |
| 关键词堆砌 | 不制定关键词密度目标，不在标题、正文、锚文本或 alt 反复塞词 |
| 域名、路径关键词与 TLD | 不承诺关键词域名或路径带来排名提升；TLD 结合业务与目标地区判断 |
| 内容长度 | 不规定“排名所需字数”；以完整回答任务和去除冗余为准 |
| 子域与子目录 | 不宣称某种结构普遍更利于排名，不为此默认建议迁移 |
| PageRank | 不把链接数量或单一链接指标当作整体搜索表现的替代品 |
| 重复内容“处罚” | 不把自身多 URL 的重复直接判为处罚；与抄袭、垃圾内容分别判断 |
| 标题数量与顺序 | 不把单一 H1 数量或标题顺序设为 Google 排名硬门槛；仍可为读者与无障碍改善结构 |
| E-E-A-T 直接排名因素 | 不把它当作单一直接排名因素，不生成所谓排名分数或承诺；检查经验、来源与可信信息的具体证据 |

## 容易误判时加载的官方边界

- **发现与索引：**[技术要求](https://developers.google.com/search/docs/essentials/technical?hl=zh-cn)说明公开可访问、正常响应与可索引内容只是资格，不能保证收录。[`site:` 运算符](https://developers.google.com/search/docs/monitor-debug/search-operators/all-search-site?hl=zh-cn)不返回完整索引清单，无结果也不证明未索引。
- **robots 与 noindex：**[robots 英文说明](https://developers.google.com/search/docs/crawling-indexing/robots/intro?hl=en)区分抓取控制与搜索排除；[noindex 说明](https://developers.google.com/search/docs/crawling-indexing/block-indexing?hl=zh-cn)要求规则可被抓取读取。禁抓与 noindex 叠加可能使后者无法被发现；敏感内容需要访问控制。
- **canonical：**[规范网址指南](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls?hl=zh-cn)将其用于重复或高度相似内容。它是信号；不要用 robots、移除工具或 noindex 代替站内规范化，也不要让 sitemap、链接与 canonical 指向相互冲突的目标。
- **标题与描述：**[标题链接](https://developers.google.com/search/docs/appearance/title-link?hl=zh-cn)和[摘要](https://developers.google.com/search/docs/appearance/snippet?hl=zh-cn)由 Google 自动生成。两者没有 Google 规定的硬性字符上限；设备呈现会截断，描述也不一定被采用。
- **结构化数据：**[常规指南](https://developers.google.com/search/docs/appearance/structured-data/sd-policies?hl=zh-cn)要求内容真实、相关且用户可见。技术验证通过不保证富结果；不得制造评价、身份或资格，也不能把 schema 当作内容质量的替代品。
- **链接：**[链接最佳实践](https://developers.google.com/search/docs/crawling-indexing/links-crawlable?hl=zh-cn)支持有真实 `href` 的锚链接；正常外部引用、付费与用户投稿应区别处理，而非全部 nofollow。

## 来源使用规则

所有链接均为 Google 官方来源，以上日期表示本次阅读核验时间，不代表今后永久有效。遇到中文翻译歧义、版本更新或表述冲突，复查相应英文文档及当前具体功能说明，并记录尚未解决的差异。特别是 robots 简中简介首段存在与英文不一致的表述，不应据此混淆抓取与索引。

本指南覆盖 SEO 基础，不单独证明任何 GEO 平台的引用规则或效果；相关结论需要另查对应平台官方说明。
